GOT QUESTIONS?

FAQ for the Curious

Is my confidential file really safe? expand_more

Yes, 100%. Open your browser's Network tab in DevTools before using any tool. You will observe exactly zero upload requests (`POST` or `PUT`) carrying document bytes. Everything is decoded in local browser memory.

Can I use this on my phone or tablet? expand_more

Yes! The boxy UI is fully responsive with finger-friendly touch targets, smooth canvas signatures, and touch drag-and-drop page sorting.

Is there any file size limit? expand_more

No! General PDF tools (Merge, Split, Compress, Convert, Edit, etc.) have 100% unlimited file capacity with zero server caps. You can process documents of any size — 100 MB, 500 MB, 1 GB, or multi-gigabyte files in local RAM. Sensitive security tools (Protect, Unlock, Sign, Redact) feature a generous 5 GB memory protection limit to ensure cryptographic stability and client RAM protection.
